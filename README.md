# Tidewell Coffee · Wins & efforts

A working cultural intervention prototype for fictional Tidewell Coffee.

Live demo: https://tidewell-wins-efforts.yinzxmail.chatgpt.site

Open `index.html` in any modern browser. The single HTML file includes all CSS and JavaScript; no setup, login, database, external assets or APIs are required.

## Features

- A structured recognition form linking effort, team impact and wider goals
- Live recognition script and visible save feedback
- Five-minute handover timer with pause, resume and reset
- Three clearly labeled fictional example records
- Shared-aloud confirmation buttons
- Browser-local persistence using localStorage
- Responsive mobile layout

Records stay in each visitor's own browser and are not shared. The CEO commitment shown in the prototype is a proposed practice, not an enacted policy.
